# Task 001 — ASO and Performance Baseline Audit

**Status:** Ready  
**Priority:** P0  
**Owner:** Claude Code for research/drafts; user for analytics access and final approval  
**Risk:** Low; research and drafting only

## Objective
Create an evidence-backed snapshot of the current Dues listing and performance before recommending changes.

## Steps
- [ ] Inspect current App Store listing and record the date checked.
- [ ] Record title, subtitle, description, keyword field if available, screenshots, price/subscription claims, privacy URL, and supported locales.
- [ ] Verify product claims against the current listing/build or user-provided authoritative evidence.
- [ ] Research relevant search phrases and a small competitor set; cite URLs and access dates.
- [ ] Request or use a user-provided App Store Connect aggregate export. Do not assume account access.
- [ ] Summarise impressions, page views, first-time downloads, conversion, territory, proceeds/subscription metrics only when present.
- [ ] Identify 5–10 prioritised opportunities with evidence, effort, expected direction, and confidence.
- [ ] Propose one measurable next experiment without launching it.

## Deliverables
- `aso/keyword-research.md`
- `aso/listing-drafts.md`
- `analytics/baseline.md` and/or dated report under `analytics/reports/`
- Updated task with sources, limitations, and next actions

## Acceptance criteria
No fabricated metrics or claims; unknowns are explicitly labelled; raw exports remain untracked; publishing and spending are not performed.
